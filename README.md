# Truck Utilization and Freight Cost Analysis

Excel analysis of truck loading efficiency and freight cost per tonne across 6 routes from Jamshedpur.

## Objective
Find where truck capacity is wasted and estimate the cost saving from load consolidation.

## Method
- Calculated utilization (load / capacity), cost per tonne and cost per tonne-km for each trip
- Compared route-wise cost per tonne using total cost / total load
- Tested a consolidation scenario at 85% utilization

## Key results
- 24 trips, 209 tonnes moved, average utilization 71.1%
- 10 trips ran below 70% utilization
- Overall freight cost about Rs 779 per tonne
- Patna (Rs 1,120/t) and Raipur (Rs 1,061/t) were the costliest routes
- Consolidating to 85% utilization cuts trips from 24 to 21, a saving of about 12.5%

## Limitations
- Simulated data, so results are indicative only
- Saving uses average trip cost; consolidation may lengthen order lead time
